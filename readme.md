API:
    API is the acronym for Application Programming Interface
    It is basically for connecting apps and programs together

The Idea:
    The basic idea on API is the call, arguments, result and failure. Call is where the API is being called upon to accept arguments. Arguments are the values you pass into the API. Result are basically the outcome of the using the API. Then failure are the basic error we may face while using APIs.

Language And stdlibs APIs:
    The stdlibs is short for standard library. It is a python library of all python built in APIs.
    The next point is the "try and except" keywords which are basically used to identify errors but they also help to run your python program without crashing even after an error. 

System-ish APIs:
    These are APIs that help python users to communicate with other programs or their operating system. A good example is the "OS" module.


Extras; Explaining json.dump and json.load:
    json.dump() is an API that coverts python objects to JSON text. json.load() is the reverse of json.dump(), meaning it converts JSON text to python objects.
